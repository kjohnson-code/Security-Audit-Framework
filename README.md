# Security-Audit-Framework
---
(Overview) 
Simulated corporate security audit focusing on vulnerability discovery, risk assessment and mitigation strategies.
---
(Executive Summary)
Assessment Period: August 2026
Target Environment: Simulated Assessment of Botium Toys
Overall Posture: Moderate Risk with critical vulnerabilities identified in perimeter defenses.
---
(Scope of Assessment)
The security audit focused on the following components within the simulated environment:
External Perimeter: Security protocol in place to notify EU customers within 72 of possible breach.
Internal Network: IT department has not installed IDS, physical stores and main offices has sufficient locks and up to date CCTV survaillence, functioning fire detection and prevention system.  
Configuration: Botium Toys employees currently have access to internal store data and possible cardholder data and customers PII and SPII.
---
 (Methodology & Frameworks)
To ensure standardisation and professional rigor, the audit aligned with recognized industry frameworks:
"Phases"
  1. Reconnaissance & Information Gathering
  2. Vulnerability Scanning & Analysis
  3. Risk Assessment & Validation
  4. Reporting & Remediation Planning

(Key Findings & Risk Matrix)
| Severity | Vulnerability | Description / Impact |
| **High** | No disaster recovery plan in place in case of an attack, no back ups of critical data. 
| **Medium** | No centralized password management system. Requirements are nominal 
| **Low** | There are no levels of access control system being used for least privilege and separation of duties has not been implemented. 
---
Recommendations & Remediation Plan
For the vulnerabilities identified above, the following mitigation steps were recommended:
1. **Immediate Patching:** Apply the latest security patches to all operating systems and third-party software packages.
2. **Hardening Configurations:** Enforce stricter password complexity requirements and disable default administrative services.
3. **Monitoring:** Implement continuous log monitoring and network segmentation to isolate critical infrastructure.
